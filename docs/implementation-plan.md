# 首版实施范围与进度

更新：2026-09-11。以本页的已确认行为为首版实施依据；完整愿景保留在 [requirements.md](requirements.md)。

## 已确认的产品行为

| 项目 | 首版决定 |
| --- | --- |
| 自动发送 | 已取消预览；会话翻译开关开启后 Enter 翻译并直接发送，关闭后普通发送 |
| 语言范围 | 本版仅中文 ↔ 英文；默认发送英语，可在设置及会话切换中英，旧版其他目标迁移为英语 |
| 接收语言 | 英文转简体中文；默认原文下方显示译文，可关闭原文显示；失败时保留原文 |
| 私信 | 首次确认启用并配置 Key 后默认开启；全局关闭优先于会话配置 |
| 频道 | 默认关闭，频道/私信名称旁的小开关控制，不占用输入区 |
| 数据传输提示 | 首次启用前明确提示消息将发送至阿里云 |
| 上下文 | 默认关闭，可设置最近 1–10 条，每条最多 1000 字符 |
| 会员系统参考 | 已读取其私信、频道实时翻译服务；本项目不修改会员系统 |

单条 Discord 消息是共享内容；发送端选定一种目标语言后，其他用户看到相同的发送文本。各用户自动显示各自语言需要接收端支持，不属于单个发送客户端能保证的行为。

## 复用与新增

| 模块 | 处理方式 |
| --- | --- |
| Qwen 调用协议 | 复用会员系统的 OpenAI 兼容 REST 接口方案，默认 qwen-turbo |
| 翻译 Prompt | 选用频道服务的中、英聊天 Prompt，保留品牌和型号；追加格式保护及不执行消息指令的约束；背景与最后待译消息分开发送，避免翻出参考上下文 |
| 语言判断 | 中文占主体的接收消息本地跳过，纯代码、链接、表情跳过；含其他文字系统的消息不自动翻译；拉丁文字的具体语言理解交给 Qwen，本地规则不是完整语言分类器 |
| 短消息 | 不移植原实现的 2/3 字符过滤，“Hi”等仍可翻译 |
| 长消息 | 超过 8000 字符报错保留草稿，不静默截断 |
| 缓存 | 新增，已读取的会员系统两个聊天服务中未发现通用缓存 |
| 上下文 | 新增，已读取的两个服务并未发送最近对话 |
| 数据存储 | 使用 Electron 本地存储，不移植 NestJS/TypeORM 数据库与广播层 |

会员系统来源文件：`xikii-api/src/messages/dm-translation.service.ts`、`xikii-api/src/chat-channels/message-translation.service.ts`。只复用相关实现，不复制其配置、密钥、日志或业务数据库。

## 缓存和上下文的实现约束

- 内存 LRU，默认 500 条，最多 2000 条，30 分钟 TTL，退出清空；可手动清空或设置为 0 禁用。
- 缓存身份涵盖原文、目标语言、模型、地域、有效上下文、Prompt 版本及密钥身份；不把 Key 写入缓存键明文。
- 同一请求的并发调用合并。默认并发 2、可设 1–4，最多等待 40 条请求，超时 25 秒；失败不缓存、不无限重试。
- 配置或 Key 变更时取消旧请求并清缓存，旧请求不能重新填充缓存或发送译文。
- 上下文只从当前会话已渲染消息取最近 N 条，不主动拉取历史、不跨频道、不落盘。接收翻译仅取待翻译消息之前的内容。
- DOM 必须带有匹配当前频道 ID 的消息容器，路由切换后残留的其他会话 DOM 不参与翻译。
- 每个会话保留最近 30 条已观察消息，最多保留 50 个会话；按消息 ID 精确排序，支持编辑更新和虚拟列表卸载后的语境保留。设置变更、退出时清空。不能获知未打开会话的新消息，也无法可靠区分离屏卸载与远端删除，因此可能短暂保留已删除消息的旧语境。

## 首版限制与后续范围

首版只处理当前打开会话、最近 30 条已渲染且位于视口的文本消息。后台会话、附件内容、图片、语音和历史批量翻译不在首版内。

富文本发送保留提及和自定义表情节点，仅逐段替换可编辑文字，并保留段落边界。占位符丢失、重复、顺序变化或草稿被修改时不会自动发送。已通过真实 Slate/React 本地测试，Discord 当前版本的实际提及和表情仍须人工复核。纯文本形式的 Markdown、代码、URL、Discord 原始提及标记会保护。实际 Discord DOM 变化时应更新独立的适配模块，不使用账号 Token 或私有 API。

备用翻译使用用户自己配置的 LibreTranslate 服务，默认关闭，不传入上下文。协议与故障流程已通过本地模拟，未连接真实 LibreTranslate 模型服务做质量评测。多目标语言输出按最新要求不在本版范围。Windows 之外的平台尚未运行验证。

## 验收步骤

1. 新配置启动：未确认前不向 Qwen 发消息，Key 不出现在远程网页或磁盘明文中。
2. 配置 Key 并确认启用：私信收到英语消息，在原文下方显示中文；中文及纯代码/表情消息不产生翻译调用。
3. 会话翻译开启：中文 Enter 后翻译并直接发送，不出现预览或工具栏。
4. 一次 Enter 只触发一次译文发送；关闭开关时普通发送。Shift+Enter 换行，中文输入法确认不触发翻译。
5. API 失败、限流、超时：原文草稿保留，接收消息仍可读。
6. 翻译期间改草稿或切频道：旧结果不替换新草稿、不发送到其他频道。
7. 普通频道默认关闭；手动开启后生效，重启后设置保留。
8. 开启上下文：仅包含本会话前 N 条；禁用时请求体完全不携带上下文。

9. 正常退出再启动保留登录；主动登出不自动重新登录。开机启动勾选与取消可保存，Windows 登录后按设置启动。
10. 后台收到私信/提及时核对托盘计数、任务栏闪烁、桌面通知和声音，点击真实消息通知应打开对应会话。系统勿扰及频道静音按设置生效。
